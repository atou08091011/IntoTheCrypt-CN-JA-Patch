# Into the Crypt — 语言切换补丁 v2026.11.12 / 言語切り替えパッチ

**v2026.11.12** ｜ 对应 Steam《Into the Crypt》（AppID 1879270）2026-11-12 更新后的 **v1.33**

## 中文说明

### 能切换到哪些语言？

右上角那个国旗按钮里一共列了 **12 种**。这个补丁附带了其中 **2 种**的官方译文表，其余语言按钮可以选，但没有译文数据，选了界面仍是英文：

| 按钮上显示 | 语言码 | 装好以后 |
| --- | --- | --- |
| **简体中文** | `zh-Hans` | ✅ 整屏中文（官方译文 9654 条） |
| **日本語** | `ja` | ✅ 整屏日语（官方译文 9654 条） |
| English | `en` | 英文原版，游戏本来就是英文 |
| Español | `es` | ⚠️ 按钮可选，内容仍是英文 |
| Français | `fr` | ⚠️ 按钮可选，内容仍是英文 |
| Deutsch | `de` | ⚠️ 按钮可选，内容仍是英文 |
| 한국어 | `ko` | ⚠️ 按钮可选，内容仍是英文 |
| Português (Brasil) | `pt-BR` | ⚠️ 按钮可选，内容仍是英文 |
| Polski | `pl` | ⚠️ 按钮可选，内容仍是英文 |
| Türkçe | `tr` | ⚠️ 按钮可选，内容仍是英文 |
| Italiano | `it` | ⚠️ 按钮可选，内容仍是英文 |
| Română | `ro` | ⚠️ 按钮可选，内容仍是英文 |

想让上面 ⚠️ 的语言也显示译文，只要把对应的 `<语言码>.json`（例如 `de.json`）放进 `Into the Crypt_Data/StreamingAssets/Localization/`，重开游戏就生效，**不用重装补丁**。文件格式为 `{"entries":[{"k":"键","t":"译文"}]}`（UTF-8）。

### 装好以后会看到什么？

- 主菜单**整屏**变成中文 / 日语：「继续单人游戏」「存档位 1」「进度」「更新日志」／「ソロで続ける」「セーブスロット1」「進捗」「パッチノート」。
- 进游戏后的卡牌说明、事件、成就、图鉴等也是中文 / 日语，用的是官方译文，不是机翻。
- 右上角国旗按钮点了**当场切换，不用重启游戏**。
- **不会多弹出任何窗口**：补丁自制的白色小窗、BepInEx 的黑色控制台都不显示。

### 怎么装？

1. 先退出游戏。
2. 把 Releases 里的 zip 解压到游戏根目录（和 `Into the Crypt.exe` 同级），提示覆盖时选「是」。
3. 从 Steam 正常启动游戏。

> 如果之前装过旧版补丁、游戏更新后一打开就闪退，用这个包覆盖安装即可恢复正常。

简体中文和日语的译文表已经放在包里了，不用另外找文件。第一次启动可能白屏 30–60 秒（在生成运行所需的组件），之后就正常，**别删 `BepInEx/core/`**。

### 想固定每次启动的语言？

点右上角按钮选就行。也可以改 `BepInEx/config/com.touge.itch.languageswitcher.cfg`：

```ini
[General]
DefaultLanguage = zh-Hans     ; 也可填 ja；留空 = 保持游戏默认（英文）
```

### 会不会影响英文或其他语言？

不会。补丁只是把游戏本来就内置、但默认关掉的语言开关打开，英文一个字都没动，随时可以切回去。游戏存档、成就也不受影响。

### 为什么有些文字还是英文？

官方译文表**本身**就留了 191 条没译 —— 82 条事件叙事（进地牢后的场景描述）、108 条「Crypt Ledger」手记、1 条界面标签。补丁已经把这两类文本的开关打开了，但官方压根没给译文，所以这些地方会一直是英文，跟补丁无关。想补的话得自己翻译；注意保留 `[yellow]…[/yellow]` 这类富文本标签、`{N1}` 占位符和原有换行。

### 打开游戏闪退 / 语言没变，怎么办？

- 闪退：确认用的是 **v2026.11.12** 这个包（游戏 2026-11-12 更新过），覆盖安装一次。
- 语言没变：看 `BepInEx/LogOutput.log` 里 `[LangPatch]` 开头的行。`Translation table 'zh-Hans': ... -> FOUND` 表示译文表在；`MISSING` 表示文件没放对位置。

## 日本語の説明

### どの言語に切り替えられますか？

右上の国旗ボタンには **12 言語**が並んでいます。このパックには **日本語 `ja` と簡体字中国語 `zh-Hans`** の公式翻訳テーブル（各 9654 件）を同梱しています。この 2 つはメインメニューからゲーム内テキストまで完全に翻訳されます。

`English (en)` は元々の英語表示です。`Español (es)` / `Français (fr)` / `Deutsch (de)` / `한국어 (ko)` / `Português (Brasil) (pt-BR)` / `Polski (pl)` / `Türkçe (tr)` / `Italiano (it)` / `Română (ro)` はボタンで選べますが、翻訳データが同梱されていないため**表示は英語のまま**です。使いたい場合は `<言語コード>.json` を `Into the Crypt_Data/StreamingAssets/Localization/` に置いてください（形式は `{"entries":[{"k":"キー","t":"訳文"}]}`、UTF-8）。ゲームの再起動だけで反映されます。

### 何が変わるか / インストール

- メインメニューがすべて日本語に：「ソロで続ける」「セーブスロット1」「進捗」「パッチノート」など。カード説明・イベント・実績・図鑑も公式翻訳で日本語になります（機械翻訳ではありません）。
- 右上のボタンで**その場で**切り替わり、再起動は不要。選んだ言語は次回起動時も記憶されます。
- 余計なウィンドウ（白い言語ウィンドウ、BepInEx の黒いコンソール）は一切出ません。
- ゲームを終了し、ZIP をゲームのルートフォルダ（`Into the Crypt.exe` と同じ場所）に展開して上書きし、Steam から起動してください。旧版パッチを入れたままゲーム更新後に起動時に落ちるようになった場合も、このパックの上書きで直ります。
- 起動時の言語を固定したい場合は `BepInEx/config/com.touge.itch.languageswitcher.cfg` の `DefaultLanguage = ja` を編集してください。

### よくある質問

- **英語やセーブデータに影響しますか？** いいえ。ゲーム内蔵の言語スイッチをオンにするだけです。英語は一切変更されず、いつでも切り戻せます。セーブデータ・実績にも影響しません。
- **一部のテキストが英語のままなのはなぜですか？** 公式翻訳テーブルに**最初から訳が入っていない 191 件**があります（イベントの情景描写 82 件、Crypt Ledger の手記 108 件、UI ラベル 1 件）。パッチ側でスイッチは有効にしていますが、公式が訳を提供していないためです。補う場合は `[yellow]…[/yellow]` などのリッチテキストタグ、`{N1}` プレースホルダー、改行を保持してください。
- **起動しない / 言語が変わらないときは？** v2026.11.12 のパックを上書きしてください。ログは `BepInEx/LogOutput.log` の `[LangPatch]` 行を確認してください（`FOUND` = 翻訳テーブルあり、`MISSING` = 配置場所の誤り）。
- 初回起動時、コンポーネント生成のため 30〜60 秒ほど白画面になることがあります。**`BepInEx/core/` は削除しないでください**。テキストのみのローカライズで、音声は関係ありません。
