# Into the Crypt — 语言切换补丁 v2026.11.12a / 言語切り替えパッチ

**v2026.11.12a** ｜ 对应 Steam《Into the Crypt》（AppID 1879270）2026-11-12 更新后的 **v1.33**

装好以后，游戏里的文字会按**官方原版译文**显示你选的语言；右上角带国旗的按钮随时能切，关掉游戏再打开也记得上次的选择。这一版把**全部 11 种官方译文**都放回来了，不用另外下载任何东西。

## 中文说明

### 能切换到哪些语言？

右上角国旗按钮里的 **12 种全部可用**。除英文是游戏原生显示外，其余 **11 种都附带官方原版译文**（每种 9654 条），点一下就整屏切换：

| 按钮上显示 | 语言码 | 装好以后 |
| --- | --- | --- |
| **简体中文** | `zh-Hans` | ✅ 整屏中文 |
| **日本語** | `ja` | ✅ 整屏日语 |
| **Deutsch** | `de` | ✅ 整屏德语 |
| **Español** | `es` | ✅ 整屏西班牙语 |
| **Français** | `fr` | ✅ 整屏法语 |
| **Italiano** | `it` | ✅ 整屏意大利语 |
| **한국어** | `ko` | ✅ 整屏韩语 |
| **Polski** | `pl` | ✅ 整屏波兰语 |
| **Português (Brasil)** | `pt-BR` | ✅ 整屏巴西葡萄牙语 |
| **Română** | `ro` | ✅ 整屏罗马尼亚语 |
| **Türkçe** | `tr` | ✅ 整屏土耳其语 |
| English | `en` | 英文原版（游戏默认，不需要译文表） |

这 11 份译文都是游戏**官方原版**，不是机翻，也不是补丁自己编的词。已经全部放进包里的 `Into the Crypt_Data/StreamingAssets/Localization/`，装完直接可用。

> 游戏 2026-11 更新时把这个文件夹清空了，所以之前选什么语言都只能显示英文。这一版把官方的 11 份表都补了回来。

### 装好以后会看到什么？

- 主菜单**整屏**变成你选的语言。比如中文「继续单人游戏 / 存档位 1 / 进度 / 更新日志」、德语「Solo fortsetzen / Speicherplatz 1 / FORTSCHRITT / Patchnotes」、韩语「솔로 이어하기 / 저장 슬롯 1 / 진행도 / 패치 노트」。
- 进游戏后的卡牌说明、事件、成就、图鉴等也是对应语言，用的是官方译文。
- 右上角国旗按钮点了**当场切换，不用重启游戏**。
- **不会多弹出任何窗口**：补丁自制的白色小窗、BepInEx 的黑色控制台都不显示。

### 怎么装？

1. 先退出游戏。
2. 把 Releases 里的 zip 解压到游戏根目录（和 `Into the Crypt.exe` 同级），提示覆盖时选「是」。
3. 从 Steam 正常启动游戏。

> 如果之前装过旧版补丁、游戏更新后一打开就闪退，用这个包覆盖安装即可恢复正常。

第一次启动可能白屏 30–60 秒（在生成运行所需的组件），之后就正常，**别删 `BepInEx/core/`**。

### 想固定每次启动的语言？

点右上角按钮选就行。也可以改 `BepInEx/config/com.touge.itch.languageswitcher.cfg`：

```ini
[General]
DefaultLanguage = zh-Hans     ; 也可填 ja / de / es / fr / it / ko / pl / pt-BR / ro / tr；留空 = 保持游戏默认（英文）
```

### 会不会影响英文或其他语言？

不会。补丁只是把游戏本来就内置、但默认关掉的语言开关打开，英文一个字都没动，随时可以切回去。游戏存档、成就也不受影响。

### 为什么有些文字还是英文？

官方译文表**本身**就留了 191 条没译 —— 82 条事件叙事（进地牢后的场景描述）、108 条「Crypt Ledger」手记、1 条界面标签。补丁已经把这两类文本的开关打开了，但官方压根没给译文，所以这些地方会一直是英文，**切换成哪一种语言都一样**，跟补丁无关。想补的话得自己翻译；注意保留 `[yellow]…[/yellow]` 这类富文本标签、`{N1}` 占位符和原有换行。

### 打开游戏闪退 / 语言没变，怎么办？

- 闪退：确认用的是 **v2026.11.12a** 这个包（游戏 2026-11-12 更新过），覆盖安装一次。
- 语言没变：看 `BepInEx/LogOutput.log` 里 `[LangPatch]` 开头的行。`Translation table 'de': ... -> FOUND` 表示译文表在；`MISSING` 表示文件没放对位置。

## 日本語の説明

### どの言語に切り替えられますか？

右上の国旗ボタンの **12 言語すべてが使えます**。英語 `en` は元々の英語表示で、ほかの **11 言語には公式の翻訳データ**（各 9654 件）をすべて同梱しています：

`日本語 ja` / `簡体字中国語 zh-Hans` / `Deutsch de` / `Español es` / `Français fr` / `Italiano it` / `한국어 ko` / `Polski pl` / `Português (Brasil) pt-BR` / `Română ro` / `Türkçe tr`

どれを選んでもメインメニューからゲーム内テキストまで**その言語で表示されます**（機械翻訳ではなく公式翻訳）。2026-11 のゲーム更新で空になっていた `Localization` フォルダに、公式の 11 ファイルをすべて復元して同梱しました。追加ダウンロードは不要です。

### 何が変わるか / インストール

- メインメニューが選んだ言語に：「ソロで続ける」「セーブスロット1」「進捗」「パッチノート」など。カード説明・イベント・実績・図鑑も公式翻訳で表示されます。
- 右上のボタンで**その場で**切り替わり、再起動は不要。選んだ言語は次回起動時も記憶されます。
- 余計なウィンドウ（白い言語ウィンドウ、BepInEx の黒いコンソール）は一切出ません。
- ゲームを終了し、ZIP をゲームのルートフォルダ（`Into the Crypt.exe` と同じ場所）に展開して上書きし、Steam から起動してください。旧版パッチを入れたままゲーム更新後に起動時に落ちるようになった場合も、このパックの上書きで直ります。
- 起動時の言語を固定したい場合は `BepInEx/config/com.touge.itch.languageswitcher.cfg` の `DefaultLanguage` に上記の言語コードを指定してください（既定は `zh-Hans`）。

### よくある質問

- **英語やセーブデータに影響しますか？** いいえ。ゲーム内蔵の言語スイッチをオンにするだけです。英語は一切変更されず、いつでも切り戻せます。セーブデータ・実績にも影響しません。
- **一部のテキストが英語のままなのはなぜですか？** 公式翻訳テーブルに**最初から訳が入っていない 191 件**があります（イベントの情景描写 82 件、Crypt Ledger の手記 108 件、UI ラベル 1 件）。パッチ側でスイッチは有効にしていますが、公式が訳を提供していないためです。**どの言語を選んでも同じ**で、パッチの不具合ではありません。補う場合は `[yellow]…[/yellow]` などのリッチテキストタグ、`{N1}` プレースホルダー、改行を保持してください。
- **起動しない / 言語が変わらないときは？** v2026.11.12a のパックを上書きしてください。ログは `BepInEx/LogOutput.log` の `[LangPatch]` 行を確認してください（`FOUND` = 翻訳テーブルあり、`MISSING` = 配置場所の誤り）。
- 初回起動時、コンポーネント生成のため 30〜60 秒ほど白画面になることがあります。**`BepInEx/core/` は削除しないでください**。テキストのみのローカライズで、音声は関係ありません。
